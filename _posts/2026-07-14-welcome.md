## Writing a new post

Every post is a plain text file in the `_posts/` folder, named like:

```
_posts/YYYY-MM-DD-a-short-slug.md
```

At the top of each file is a small block called **front matter**:

```yaml
---
layout: post
title: "Your title here"
date: 2026-07-14 09:00:00 -0500
tags: [optional, tags]
---
```

Everything below that block is your writing, in
[Markdown](https://www.markdownguide.org/basic-syntax/). Commit and push, and
GitHub rebuilds the site within a minute.

If you don't want to name files by hand, run `./new-post.sh "Your Title"` from
the repo and it creates today's file for you, ready to write.

## What Markdown gives you

You get headings, **bold**, _italics_, and [links](https://example.com) for free.

> Blockquotes look like this — good for pulling out a line.

Lists work as you'd expect:

- a point
- another point
- a third

And code stays monospaced and readable:

```python
def hello(name):
    return f"hi, {name}"
```

That's the whole system. Write, commit, push. Everything else is handled.
